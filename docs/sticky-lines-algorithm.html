Sticky Lines Algorithm

The sticky lines bar shows the enclosing scope headers that have scrolled above the visible area of the diff panel, giving constant context about where you are in the file.

Core Rule

Scopes are evaluated outermost-first in a single pass on every scroll event.
A scope is shown if and only if:

  top(openLine) ≤ scrollTop + barHeight
  top(closeLine) > scrollTop + barHeight + H

H = height of one line (same in diff panel and sticky bar)
barHeight accumulates H for each outer scope already confirmed shown

The close condition uses barHeight + H (not just barHeight) because it must account for the line that would be added to the bar by this scope itself.

Scroll position is never modified. The sticky bar uses position: sticky; top: 0 inside the scroll container — it overlays content without affecting layout. scrollTop is driven exclusively by the user's scroll gesture. Adding or removing sticky lines never triggers a reflow or causes any jump in the scrolling position.

4. Adjacent open/close lines — nothing shown

1  if (foo) {    ← openLine
2  }             ← closeLine (immediately after)

The open condition (top(1) ≤ scrollTop) implies top(1) + H ≤ scrollTop + H, i.e., top(2) ≤ scrollTop + H. But the close condition requires top(2) > scrollTop + H. Contradiction — nothing is ever shown. No special filter needed.

5. } else { — atomic scope swap

7. Multiple { on one line
